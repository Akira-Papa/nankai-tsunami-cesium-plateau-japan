# 開発方針設計 初版

## 構成
既存Cesium版を同じGitリポジトリのcodex/precomputed-inundationブランチで改訂。Vite/TypeScript/Cesiumを継承。静的データはpublic/inundation、画面はVercel dist配信。外部の地形・地図・PLATEAU配信を利用する。

## モジュール責任
- データ: 公式メッシュの取得・変換・マニフェスト・出典。
- UI: 地図主体の和文UI、都市選択、ケース、凡例、地点結果、共有。
- 地図: Cesium地形・建物、最大浸水描画、点選択。
- 統合: rootがmain.tsで状態管理とUI/地図を接続。
- 品質: 自動テストと再現手順。
- 配布: Vercel設定、再生成手順、操作説明。

## 初版案
ケースごとの最大深さセルを遅延読込し、地形上に色分けする。到達秒がある場合は閾値到達済み範囲としてフィルタ。多数セルは集約表示。全国俯瞰では自治体浸水想定タイルを参考表示する案。

## 検証
型/build/単体、全国移動、地点参照、ケース競合、低帯域、欠損、モバイル、共有復元。公開はdistのみ、docsや取得原本を混入させない。

## レビュー反映後の実装契約
- src/explorerUi.ts: UIと操作状態。src/explorerState.ts: 共有URLの検証・復元。
- src/main.ts: 地図起動、地域移動、非同期世代管理、地点照会、品質・建物接続。
- src/inundationData.ts: マニフェスト検証、20秒タイムアウト、空間タイル遅延読込、25,000セル目安でLOD降格。
- src/inundationLayer.ts: 集約グリッドに合致した矩形を地形へdrape。256セルずつ分散処理、30,000セル以上は明示的拒否。
- scripts/precompute_inundation.py: 入力ZIPのCRC検査、CSV参考深さ最大と最早1cm到達を別統計として集約。原本は公開物に含めない。
- public/inundation/manifest.json: 入手できたケースだけをメニューへ掲載。100/500/2500mの集約値。100mは0.25度タイル、その他は1度タイル。
- Vercelはnpm ci→npm run build→distを配信。実行中に津波計算をしない。地形・地図・建物は外部配信依存。
- UIの時間は0〜720分。自動再生は1cm到達済み範囲の累積表示であり、現在水位・引き波・海洋伝播を推測しない。
- 共有にはcase/mode/min/opacity/buildings/photo/liteとカメラ位置・向きだけを含める。位置はユーザーが共有を操作した場合のみURLに記録する。
- 失敗時にも地図UIは起動し、取得不可理由と再試行操作を表示する。ケース変更時は旧結果を消す。

## データ粒度に伴う限界
本表示は10m原本の正確な境界を再配信しない。100m以上の範囲内に一つでも浸水原点があると着色するため、実際の浸水境界より広く見える。値は範囲内最大/最早という別統計である。UI・README・操作手順でこの意味を明示する。用途は全国の想定比較・防災学習で、個別建物の被害認定ではない。
