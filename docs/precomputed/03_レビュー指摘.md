# 開発方針レビュー指摘

実装前レビュー。既存コードと公式説明PDFを照合した。

|ID|重大度|指摘|修正要求|
|---|---|---|---|
|RV01|重大|市町村海岸最大津波高を内陸の水位にしている|既存water.tsと建物の一律水没着色を主アプリから切り離す|
|RV02|重大|全国参考タイルをケース別計算と混同する危険|計算ケース選択中は自治体統合タイルを混ぜない。別データ種として明示|
|RV03|重大|到達秒と最大深さだけで時間ごとの水深を再現できない|時間UIは到達済み範囲と明示、最大深さは最終最大値と表示|
|RV04|重大|ZIP入手と利用条件未確認で全ケース収録を約束できない|入手・形式・ライセンス確認、収録ケースを実データから生成|
|RV05|高|大量10mメッシュを全国同時描画できない|空間分割、表示範囲選択、集約と上限、集約解像度表示|
|RV06|高|旧mainは404をすべて正常扱いし読込失敗を区別しない|失敗/未収録の区別、再試行、古い選択結果を無効化|
|RV07|高|標高基準の誤差から精密な水面を誤表示しうる|深さ色は公式値、見た目の水面と数値精度を区別、地形未取得を表示|
|RV08|中|細かい住所検索には別サービス依存が生まれる|まず同梱全国自治体検索と座標入力、住所ジオコーディングを装わない|
|RV09|中|全国データがない地点を浸水なしと表現する危険|収録セルなしと表示、ゼロ・未収録を区別|
|RV10|中|5エージェント同時実行は枠上限超過|5役を3並列＋後続2役、ファイル所有権を固定|
