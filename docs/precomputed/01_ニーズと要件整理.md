# 全国3D津波シミュレーション ニーズと要件

## 目的と判断軸
実在する日本全国を3Dで探索し、南海トラフの計算済み浸水範囲・深さ・到達情報を地点と結び付けて理解する。天才心配性エンジニアは「誤った安心を与えず、データが読めない時も地図を使え、同じ条件を再現できる」ことを守る。

## 5人のニーズ
- 開発: 計算と表示を分離、静的配信で全国へ展開し再現可能にする。
- 架空の政府対策本部長: ケース・出典・堤防条件の一致、地域比較。
- 架空の被災中住民: 少ない操作で場所へ移動、読込失敗と未収録の区別。
- 架空の被災地外住民: 家族の街の検索、共有、スマホ対応。
- 架空の未来人: 学習結果を備えにつなげ、想定と実況を混同させない。

## 確認済み
ユーザー指定はVercel＋Cesium＋計算済み浸水データ。既存全国Cesiumリポジトリを改訂する。既存市町村一律水面は計算済み浸水域ではない。内閣府2025データ提供先の陸域浸水メッシュには最大深さ、閾値到達秒、地震後地盤高がある（説明PDF確認）。全国の任意断層の再計算や実況配信は今回の構成に含まれない。

## 必須要件
R1 全国3D地図、自治体検索、都市ショートカット、地形と対応建物。
R2 入手した実計算ケースを選択し、計算セルに基づく浸水表示。最大深さと到達時間の意味を分離。
R3 地点選択で値、単位、出典、ケース、表示解像度を確認。
R4 範囲外/データなし/取得失敗/読込中を区別しゼロ値へ置換しない。
R5 ケース変更時に古い結果を除去、視点を保持。非同期競合を防ぐ。
R6 URLで視点とケース等を共有。入力検証、個人情報の自動送信なし。
R7 スマホ用折りたたみ、品質切替、文字凡例、キーボード操作。
R8 Vercel静的build、秘密情報不要、必要範囲のみ遅延読込。
R9 取得できる到達データで到達済み範囲を表示。最大深さを時刻の水深と偽らない。
R10 3サイクルの実操作・障害試験・修正と証拠保存。

## 依存と完了境界
公式ZIPの取得・利用条件確認・座標系確認が先行条件。入手できないケースや波形は捏造せず未収録とする。提供データの全国範囲と3D閲覧の全国範囲は区別。最終報告は実装完了とデータ制限と公開状態を分ける。
担当: AI実装、本人の追加質問なし。次作業: データ取得と変換契約。開発時間の確約はデータ規模測定後。サブエージェント5役を3並列＋後続2役で実行。
