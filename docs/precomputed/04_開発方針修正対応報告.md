# 開発方針修正対応報告（実装前）

レビューを受け、以下を設計へ反映する。これは設計修正報告であり実装完了報告ではない。

- RV01: rootがmainを再構成し旧一律水面・海岸値からの地点深さ計算を使用しない。
- RV02: 公式Nankaiケースと自治体の最大浸水参考図を排他的なデータ選択にする。データの意味を常時表示。
- RV03: 到達モードは「指定閾値へ一度でも到達した範囲」。引き波や現時刻の水位を表すアニメーションは作らない。
- RV04: 実ZIPの取得確認後に収録ケースを確定。出典の元URLのみ保存し期限付きURLは保存しない。
- RV05: 空間タイルを遅延取得、全国表示に対応するLODを用意。集約は最大深さと最早到達を別統計として明示。
- RV06: ケース/クリック変更に世代IDを付け、読込中・失敗・未収録をUIへ返す。
- RV07: 計算済み深さを数値の正とし、見た目の地形との差を隠さない。
- RV08: 自治体名検索と都市移動を初版の検索契約とする。
- RV09: セルなし=安全ではない旨を地点結果に表示。
- RV10: データ、UI、地図の3役を先行。その後テスト、配布の2役。rootは統合・レビュー・3サイクル検証を担当。

## 修正版の採用判断
Vercel静的配信＋Cesium＋公式浸水メッシュの事前変換を採用。一律水面案は棄却。全国3D閲覧を最初から維持する。ケース数は公開原本の量と配信サイズを測定して段階追加できる契約にする。
