# 任意波源・津波高の動的計算 実装報告

## 実装した機能

左パネルで波源の津波高0.1〜30m、ピンまたは経緯度、波源sigma20〜100km、計算時間5〜120分、全国／地域範囲を選択できる。入力変更時に前結果を破棄し、Web Workerで非線形浅水方程式を再計算する。海上最大水位上昇と陸上最大浸水深を色分けし、地点クリックで数値を確認できる。

数値地形はNOAA ETOPO1から再現可能な手順で取得し、約495KBの検査値付きバイナリとして同梱。Vercelに計算サーバーや新しい有料サービスは追加していない。既存の内閣府2025計算済み表示、自治体検索、PLATEAU地形・建物を維持した。

5名を地形データ、数値solver、左パネル、Cesium描画、独立レビューへ割り当て、主担当が統合。要件→設計→レビュー→修正報告を作成後に実装した。

## 確認

3サイクルのブラウザ検証10/13/13項目、既存公式機能11項目、ユニット78件が成功。実地形の120分計算と理論物理との整合性検証も実施。詳細は08および06を参照。

## 精度の未達

「現実の津波が、どの建物まで何m浸水するか」を精密に予測する要求は未達。今回完成したのは、粗い実地形で任意条件を都度計算できる実験機能である。ピンは断層モデルの代用、選択高は沿岸到達高ではなく初期海面上昇。地形の間引き、平面近似、摩擦・防潮施設等の省略により現実の値を保証しない。
