# 任意の津波高・波源で計算する使い方

1. 左の「任意条件で計算」を選択します。初回は東経134度・北緯32度の仮想波源で計算します。
2. 「波源の津波高」を変更します。ここでの高さは波源の初期水面上昇量です。各沿岸に届く高さを指定するものではありません。
3. 「地図の海上にピンを置く」を押し、海をクリックします。経度・緯度の入力もできます。陸上・範囲外は計算しません。
4. 波源の広がり・計算時間・全国周辺／波源周辺の計算範囲を選択します。変更後に前の結果を消し、自動で再計算します。中止・再計算もできます。
5. 計算完了後、海は青、陸の浸水は黄〜赤で表示します。色は計算期間内の最大値で、同一時刻の水面ではありません。
6. 地図をクリックすると、そのセルの地盤高・海上水位上昇または陸上浸水深を確認できます。都市検索で街に移動しても計算条件は保持します。
7. 「公式の計算済み」に戻すと、内閣府2025の想定ケースを閲覧できます。任意条件の共有URLは現在未対応です。

## モデルの意味

ブラウザで実際の浅水方程式を時間積分します。公式データの倍率変更ではありません。ただし波源をガウス状の水面上昇で代用し、断層破壊は計算しません。底面摩擦・堤防・建物・潮汐等を含まず、平面距離を使います。

数値地形はNOAA ETOPO1（2009年モデル、平均海面基準）。全国は0.1度、地域は0.05度です。緯度方向は約11.1km／5.6kmで、細かな沿岸低地や河川の浸水を正しく計算できません。実際の地形・3D建物の表示精度と、計算精度は異なります。

計算範囲は東経122〜150度・北緯24〜46度。地域設定はその中の波源±3度です。枠外は未計算、0.01m以下は透明です。無着色から安全とは判断できません。実際の浸水予測や避難判断に使える精度は未達です。

## 再現と開発

- `npm test`：数値基礎・理論との整合性・表示境界・既存機能。
- `npm run build`：型検査とVercel向けビルド。
- `node scripts/qa-simulation-physics.mjs`：同梱実地形で120分の計算。
- `QA_BASE_URL=http://127.0.0.1:5285 QA_RUN=local node scripts/qa-dynamic.mjs`：起動済みpreviewへの実ブラウザ検証。Playwrightを利用可能な環境で実行。
- 地形再生成は `python3 scripts/prepare_simulation_terrain.py --help` と地形台帳を参照。
