# ピン連続配置で再計算されない不具合

2026-09-05、利用者の指摘を受け公開URLで実際のクリック操作を再検証。

## 原因と再現

旧実装はピンを1回置くとpicking=falseへ自動変更し、以後のクリックを地点の読取として処理していた。1回目の波源は133.951E/31.993Nに変わったが、2回目の別の海上クリックでは同じ座標と計算結果が残った。前回のテストは配置ボタンを押した直後の1回のクリックだけを確認しており、連続配置の問題を見落とした。

## 修正

- 任意条件モードに入った時点でピン配置を有効化。
- 1回配置してもモードを維持し、海上クリックのたびに旧結果を消去して再計算。
- 「浸水深を調べる」を別ボタンにし、波源配置と地点調査を明示的に切替。
- 完了表示に計算した波源の経度・緯度を追加。

## 確認方法

`scripts/qa-pin-placement.mjs` は実マウスクリックとタップを使う。座標の変更だけでなく、実際にWorkerへ渡された計算条件と計算結果配列の重み付き合計が変わることを検証。アプリのhandleClick関数を直接呼ぶ試験ではない。

本番用ビルド上でPC連続3クリック、連打による古い結果の破棄、地点調査・配置の再開、スマホ連続2タップの計7項目を確認。ページエラー0。既存の動的計算13項目とユニット78件も確認。
