# 日本海側・50m対応と計算の正しさのレビュー

## 結論

50mまでの仮想波源と日本海側4地点を操作できるようにした。計算の初期条件に問題を発見し修正した。ただし「現地の浸水深が正確に予測できる」という要求は未達。断層モデルの代わりに任意の初期水面上昇を置く実験機能であり、修正と安定性試験をもって予測精度の保証とはしない。

## 機能

- 高さ選択0.1〜50m。solverも50mを受理し、50m超は拒否。
- 能登半島沖136.5E/38N、新潟沖138E/38.5N、秋田沖138.5E/40N、北海道西方沖139E/43.5N、四国沖134E/32Nの仮想波源。選択で地図・ピン・計算を更新。
- 任意の日本海側の海上もピンで指定できる。公式の日本海断層モデルを再現する選択肢ではない。
- 20/30/50mの色階級を追加。50mは初期上昇の入力上限であり、沿岸での計算結果を50mへ切り詰めるものではない。

## 発見・修正した初期条件の問題

旧コードは外海接続マスクと波源からの直線距離だけで初期Gaussianを配置した。このため、陸地の反対側の海にも、波が陸地を回り込む前から初期変位を置いていた。単一海域の仮想波源という操作の意味と一致しない。

実際に高さ100mの陸壁を挟んだ合成地形で、波源30m・sigma20km・経過1秒なのに反対側が25.695mとなることを確認した。

修正は海セルを通る8近傍最短経路に基づく初期波源の範囲制限。経路長6sigma以内だけを候補とし、その範囲内の初期振幅を従来のGaussianで与える。斜めに陸セル角をすり抜けない。水深や外海の初期状態そのものは変更しない。これは単一海域の実験波源の定義修正であり、実際の断層変位に対する解ではない。

## 検証

- 合成地形：陸壁の反対側を初期に持ち上げないこと、半島を迂回する水路が遠い場合にも初期変位を置かないことを検証。
- 50mの入力受理、50m超の拒否、非負水深・有限値・対称性、静水保持、乾燥盆地・高障壁、理論水量保存と波速への収束を検証。ユニット81件成功。
- 実地形：日本海4地点＋四国沖、全国0.1度／地域0.05度、各50m・sigma100km・120分、計10条件を完走。全水深が有限・非負であることを確認。数値は `evidence/japan-sea/physics.json`。
- 日本海各地点について全国／地域で浸水値の差が残る。特に秋田沖の同じ仮想条件で最大陸上深さが28.47m／79.57mと大きく異なり、予測精度を保証できない証拠である。両者は範囲も違うため厳密な格子収束比較ではない。

## 正確な浸水予測にまだ必要なもの

- 観測・公式想定と照合した断層変位と波源条件。
- 海底・沿岸の高解像度地形、標高基準の統一、海岸線・水路の解像。
- 球面座標の距離・面積、広域／沿岸の境界接続、反射と長時間計算の検証。
- 底面摩擦、堤防・河川・構造物、乾湿遷移と遡上の専門ベンチマーク。
- 過去津波の観測値との誤差評価と専門家レビュー。

現行の固定平面距離近似・数kmの点抽出地形・一次精度・摩擦なしの計算では、この条件を満たせない。全国地図を表示できることと、全国の任意地震を正確に予測できることを分ける。
