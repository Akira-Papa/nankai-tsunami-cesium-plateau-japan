# ピン配置ボタンと計算中表示

地図上に常時表示するオレンジ色の「📍 ピンを立てる」ボタンを追加。公式モードからも、このボタンで任意計算のピン配置へ移る。左パネルのボタンも大型化し、高さのスライダーより上へ移動。ピン配置中の案内と十字カーソルで現在の操作を示す。連続クリックの都度再計算する動作は維持。

条件変更後の待機、数値地形の読込、Web Worker計算、結果画像の準備が終わるまで、地図上にスピナー・計算中の説明・進捗・中止ボタンを表示。読込中は未確定のプログレス、計算中は実際の計算時間に基づく進捗。完了・中止・モード離脱・エラーですぐに閉じる。古い処理は新しいローディング状態を変更しない。
