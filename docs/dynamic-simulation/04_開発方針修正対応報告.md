# 設計レビュー 修正対応報告

実装前に上記レビューを反映した最終契約。

|指摘|対応|
|---|---|
|1|入力名「波源の津波高（初期水面上昇）」、ピン名「仮想波源（震源位置の代用）」とする。専門家検証済みの災害予測とは表示しない。|
|2,8|全国3D閲覧を維持。数値計算の範囲は122–150E/24–46N。地域計算はその範囲内の波源±3度。領域枠と解像度、結果が地域限定であることを明示。|
|3|海は水位上昇、陸は浸水深を別凡例・地点説明で表示。|
|4|静水と乾湿を含む基礎試験に加え、実データの計算をブラウザで実行。異常な数値は失敗として結果を破棄。専門機関の精度認証は未達として残す。|
|5,6|条件変更・モード離脱でWorker終了、進捗・結果・地点説明をリセット。データと結果の世代を照合。|
|7|計算時間は5–120分、波高0.1–30m、sigma20–100km。全国0.1度／地域0.05度。画面操作は主スレッド。|
|9|任意条件モード中の共有は独自条件に対応するまで無効にして理由表示。|

5名の担当を、同時実行可能数に合わせ3名→2名で配置する。主担当は既存画面との統合、結果の検証、GitHub/Vercel反映を行う。実装後に実測・不具合・修正を追記した3サイクル検証報告を別途保存する。
