# 動的津波計算 開発方針設計

## 構成
VercelはHTML/JS/数値地形ファイルを静的配信する。ブラウザのWeb Workerが非線形2次元浅水方程式を解き、Cesiumに結果を重ねる。公式計算済みデータとは別の結果レイヤー・状態を持つ。

## 地形
NOAA ERDDAP etopo180 (ETOPO1、平均海面基準、WGS84) の日本周辺122–150E、24–46Nを3分角(0.05度)へ点抽出。中心座標はwest/southからstep刻み、南から北のrow-major。Int16 little endian標高とJSONメタデータを同梱する。全国計算はさらに2点おき(0.1度)、地域計算は波源±3度(0.05度)。数kmの実効メッシュ幅と矩形を表示。外海と接続する負標高セルのみを初期海水とし、内陸の負標高盆地を自動で海にしない。

## 計算
保存変数 h,hu,hv の有限体積法。静水圧再構成＋Rusanov流束、地形ソース項、CFL可変時間刻み、乾湿判定と正値性、透過境界。初期条件は海域内のガウス状水面変位、速度ゼロ。波源半径はガウスsigma。潮位0m、建物・堤防・断層・潮汐・分散・コリオリなし。平面距離近似の歪みを含む。初期上昇の質量追加を仮想条件として明示。

## 共通契約
src/simulationTypes.ts に TerrainGrid {width,height,west,south,step,elevation:Float32Array}、SimulationConfig {lon,lat,heightM,radiusKm,durationMinutes,domain:'national'|'regional'}、SimulationResult {grid, maxSurface:Float32Array,maxDepth:Float32Array,ocean:Uint8Array, elapsedSec,steps} を定義。maxSurfaceは海面基準の最大水位上昇、maxDepthは陸上の最大水深。負標高の陸上を識別するためocean配列を必須とする。

地形担当はloadTerrain()とselectGrid(grid,config)を提供。計算担当はrunSimulation(grid,config,onProgress?)およびWorkerメッセージstart/progress/result/errorを実装。主担当がWorkerを起動・terminateしてキャンセルと世代管理を行う。UI担当は独立したinitSimulationUi(container, callbacks)を実装し、既存HTML/CSSを変更しない。結果表示担当はcreateSimulationLayer(viewer)でsetResult/clear/dispose/inspectを提供。

## 公開
既存GitHub mainを更新し、既存Vercel連携で配信。数値地形を同梱し、利用時にNOAAへ問い合わせない。秘密鍵や新規有料サービスは使わない。
