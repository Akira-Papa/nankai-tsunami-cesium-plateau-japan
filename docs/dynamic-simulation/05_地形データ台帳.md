# 動的計算の数値地形台帳

## 原典と利用条件
- 提供：NOAA NGDC ETOPO1 Ice Surface、ERDDAP dataset `etopo180`。
- [提供元メタデータ](https://coastwatch.pfeg.noaa.gov/erddap/info/etopo180/index.html)。原典は Amante, C. and B. W. Eakins (2009), ETOPO1 1 Arc-Minute Global Relief Model, NOAA Technical Memorandum NESDIS NGDC-24。
- 元データは1分角、水平基準WGS84、鉛直基準Mean Sea Level、単位m・上向き正。提供元が中心座標と記載する grid/node registered データ。
- メタデータのlicenseは無料利用・再配布を認め、正確性・完全性・特定目的適合性等の保証を否定している。元文を `public/simulation/terrain.json` に同梱する。サイトのMITライセンスで地形の出典・条件を置き換えない。

## 同梱データと生成
`python3 scripts/prepare_simulation_terrain.py` で取得・検証・再生成する。

- 中心座標の範囲：経度122–150度、緯度24–46度。561列×441行。
- 1分角データから3点おきの標高を抽出（0.05度・3分角）。平均・補間・細かい地形の再構築は行わない。
- `etopo1-japan-3min.bin`：Int16 little endian、南から北・西から東のrow-major、494,802 bytes。
- `terrain.json`：取得日時、URL、寸法、座標規約、範囲、単位、min/max、SHA-256、利用条件。
- 取得時に全CSV行の座標と順序、寸法、標高範囲を検査。欠損値32767を拒否。
- ブラウザでもメタデータ・バイト長・SHA-256・欠損を検証する。失敗時は計算せず、再試行できる。

## 計算への切出し
全国はさらに2点おき（0.1度、281×221）、地域は波源±3度内の0.05度データ。地域端は保有データ範囲で切り取り、範囲外の標高を創作しない。全てのwest/southは最初のセル中心であり、左下の外縁ではない。

3分角は南北約5.6km、東西約3.9–5.1km。全国はその約2倍。海岸線・河川・堤防・建物・低地の細部は表現できず、浅い海・小島が点抽出で消える可能性がある。地点標高は測量値や建物地点の正確な地盤高を意味しない。地図の見た目の精細さと数値計算の解像度は異なる。

## 検証
`npx vitest run src/simulationTerrain.test.ts`：8件。中心座標保持、全国間引き、地域境界、範囲外拒否、形状・ハッシュ不一致、負標高のlittle endian読取、欠損拒否、取得失敗後の再試行。

取得済みデータの標高範囲：−9,726〜2,735m。SHA-256：`31c365ff79287cbef4ebf9e2397f2e11daa02aac48a92d9b0b6bab9d7ae96074`。取得処理はcurlを使用（Python標準urllibで接続待ちが長くなったため変更）。
