# ピン選択後の海岸参考表示

## 要望と修正
ピンを置いた後も、初期表示の海岸沿いの着色を維持する。既存表示の改訂として、任意条件モード切替時の公式レイヤー削除と、同モード中の表示範囲更新の停止を取り除いた。

任意計算と公式データは別レイヤーで描画する。再計算・中止は任意計算レイヤーだけを更新し、地図移動・拡大時は公式データを再取得する。任意条件モードでは公式データの最大浸水深を表示し、公式モードに戻すと元の時間表示設定を復元する。

## データの区別
海岸の色は内閣府2025の選択ケースの参考表示であり、ピン位置や初期津波高から再計算したデータではない。左パネルに出典・取得状態・任意計算との違いを表示する。日本海側など未収録範囲へ公式データを捏造しない。既存の任意計算の科学的精度・解像度はこの修正で改善されない。
