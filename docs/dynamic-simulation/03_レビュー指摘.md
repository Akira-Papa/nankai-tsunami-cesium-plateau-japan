# 設計レビュー指摘

1. P0：震源位置と高さだけで実際の津波は決まらない。ピンを仮想波源と表示し、初期変位の意味と断層モデル不使用をUIへ出す。
2. P0：数km地形を精密浸水に見せる危険。メッシュサイズ・計算領域・未検証を常時表示し、建物と同精度であると示さない。
3. P0：海面高と地面からの浸水深を混同しない。海陸マスクを結果に同梱し凡例・地点読取を分ける。
4. P1：乾燥セルで負水深やNaN、静止海面で偽波が発生しうる。静水維持、正値性、波速、対称性、保存量、実地形長時間で検証する。
5. P1：旧計算が遅れて新条件に表示される競合。入力変更時にレイヤーを消去しWorkerを破棄。結果は計算IDと一致時だけ適用する。
6. P1：領域外・陸上の波源、地形欠損、計算中止を正常な空結果と混同しない。明示メッセージと再試行を実装。
7. P1：全国計算のブラウザ負荷。粗密2設定、進捗、最大時間、Worker分離、実測を必須とする。
8. P1：全国と称しながら地形領域は一部離島を含まない。データ範囲を正確に表示し範囲外は拒否する。
9. P2：共有URLに公式ケースだけ残ると誤った再現になる。任意条件を共有に含めるか、独自試算中は公式共有を止める。
