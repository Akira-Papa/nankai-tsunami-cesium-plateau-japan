# 独立実装レビューと物理検証

対象は動的浅水試算、数値地形、UI世代管理、海陸の表示区分。別担当が実装を読み、有限体積流束をそのまま再実装する試験ではなく、連続体の保存則と理論的な波の広がりを検証した。

## 指摘と対応

|重要度|指摘|対応・確認|
|---|---|---|
|P1|maxSurface/maxDepthだけでは、負の水面変位を含む水量保存や波速を検証できない|主担当が finalDepth:Float64Array を追加。最大値の描画とは分離し、独立試験に使用。|
|P1|無効な経緯度を入力すると画面値だけ変わり、以前のconfig/結果が残る|主担当がinputイベントで更新・無効値をNaNとして渡し、旧結果を破棄するよう修正したと報告。ブラウザ操作での最終確認は統合QA担当。|
|P2|ピン選択後の表示3桁と内部の未丸め座標が異なる|主担当が丸め値を内部・表示で統一したと報告。|
|P1|画像レイヤー作成失敗がcontrollerに伝わらず、完了表示だけ残りうる|主担当へ通知。計算成功と描画成功を分け、非同期描画失敗を画面に出す必要がある。最終対応状況は3サイクル報告を参照。|
|精度制約|数kmの地形間引き、平面近似、ガウス状初期波源は精密浸水予測に不十分|初期上昇量・仮想波源・粗いメッシュ・未検証をUIに表示。以下の実地形試験でも全国/地域の差が大きく、行政の想定や現地観測に対する検証完了とは扱わない。|

## 独立物理試験

実行：`npx vitest run src/simulationPhysics.test.ts`。2件合格。

1. 一様100m海域、0.01mの小振幅ガウス波、初速0で、開境界に到達する前の追加水量を検証。初期/最終水深から直接積分した体積の相対変化が1e-6未満。最終水深が全て有限・非負。
2. 線形浅水方程式では、正規化した半径方向の二次モーメントの増分は初速0で `2 g H t²` となる。この連続体の式に対して101²と201²格子の計算を比較。細かい格子の相対誤差20%未満、粗格子に対し誤差が30%以上減少。

2は波の広がりの速度尺度√(gH)に対する整合性・一次精度の収束確認であり、海岸到達時刻や複雑な地形での遡上高の精度認証ではない。別のsolver基礎試験には静水維持、乾燥盆地、対称性、高い障壁、入力拒否がある。

## 実地形・120分計算の再現試験

実行：`node scripts/qa-simulation-physics.mjs`。実際に配信するバイナリを検査・復号し、production solverをメモリ内bundleで読み込む。アプリ成果物は変更しない。

地形SHA-256: `31c365ff79287cbef4ebf9e2397f2e11daa02aac48a92d9b0b6bab9d7ae96074`。
共通条件：134°E/32°N、初期水面上昇30m、sigma100km、計算120分。

両方とも7200秒を完走し、最終水深の全セルが有限かつ非負。最大海面上昇は両方30m。実時間はこのMac上のNodeでの観測値であり、スマートフォンやCesium描画を含むブラウザ性能を保証しない。

全国/地域では計算領域・点抽出される地形・境界が異なるため、これは格子収束試験ではない。最大浸水深が大きく変わる実測を踏まえ、建物地点の予測や安全判定には使えない。今後の精密化には高解像度地形、断層モデル、境界/領域の設計、摩擦・構造物等の物理、既知の津波に対する遡上検証が必要。
