# 任意波源・津波高を指定する動的計算：ニーズと要件

## 目的と判断
左パネルで津波の高さを変え、地図のピンで発生位置を指定し、その条件で波の伝播と陸上浸水を数値計算して、地域ごとの色と地点数値を確認する。既存の公式計算済み表示を維持する改訂。新規の別サイトやVercelプロジェクトは作らない。

## 利用者の要求
- 開発者：Vercel静的配信＋Cesiumで完結し、再計算中も地図を操作できる。
- 災害対策本部長役：公式想定と独自試算を混同しない。計算条件、範囲、未計算を把握できる。
- 被災中の住民役：現在の津波情報と誤解しない。計算結果から安全や避難時間を断定しない。
- 被災地外の住民役：日本各地に移動して条件の違いを学べる。
- 将来の検証者役：地形出典、数値手法、再現条件、検証結果が追跡できる。

## 必須要件
1. 左パネルに計算済み／任意条件の切替、波源の津波高、波源半径、計算時間、計算範囲を設置。
2. 地図クリックで波源ピンを設定できる。地点調査とは明示的にモードを分ける。陸上や範囲外は拒否。
3. 入力変更で旧結果を即時無効化し、デバウンスして再計算。計算の中止と再試行を提供。
4. 海底・陸上標高を用いる浅水方程式の時間積分。既存浸水データの倍率変更や距離減衰式で代用しない。
5. 海上は最大水位上昇、陸上は最大浸水深を区別して色表示。選択地点で地盤高、計算値、メッシュ幅を表示。
6. 全国周辺の計算領域と地域詳細領域を用意し、領域外は未計算とする。
7. Web Worker、進捗、中止、古い計算の反映防止、データ障害時の空結果を実装。
8. 5担当で実装し、物理基礎・統合操作・本番相当の3サイクルで確認と修正を記録。

## 精度の契約
ここで指定する「津波高」は波源での初期水面上昇量。沿岸到達高や震度・マグニチュードではない。ピンは仮想的な波源中心で、断層破壊の計算は含まない。ETOPO1を間引いた数kmメッシュでは河川・堤防・建物・細かい沿岸低地を表現できない。実災害の精密な浸水予測という要求は、この実装だけでは満たせない。モデルを動かせたことと実地での精度検証を分けて報告する。
