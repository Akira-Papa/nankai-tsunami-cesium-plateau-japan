# 南海トラフ 津波浸水3Dビジュアライザ 全国版（試作）使い方マニュアル

防災担当の方や一般市民の方が、はじめてでも迷わず使えるように書いたご案内です。
専門用語は最後の「用語集」でまとめてご説明いたします。

## 1. このアプリでできること

- 全国の沿岸市区町村について、実際の地形と建物を3Dで表示し、その上に「津波の高さ」に合わせた青い水面を重ねます。
- 市区町村を選ぶと、内閣府が公表した南海トラフ巨大地震の津波高（2025 年公表値・2012 年公表値）が表に出て、その値がそのまま水面の高さになります。
- スライダーやプリセットで津波の高さ（0〜35 m）を変えると、水に浸かる範囲が即座に変わります。
- 「公式浸水想定を重ねる」を ON にすると、国のハザードマップ（重ねるハザードマップ）の津波浸水想定を色分けで重ねられます。
- 地図をタップすると、その地点の「浸水深（水面と地面の差）」を数字で確認できます。

> **免責（必ずお読みください）**
> 簡易可視化であり公式想定ではありません。内閣府の津波高は海岸線での最大値で、内陸へ一律に適用すると過大・過小になります。
> 避難判断は各自治体のハザードマップを参照してください（[ハザードマップポータルサイト](https://disaportal.gsi.go.jp/)）。

## 2. 起動方法（開発者向け）

| 手順 | コマンド／操作 | 補足 |
|---|---|---|
| 1 | `npm install` | 初回のみ。Node.js 20.19 以上が必要です |
| 2 | `npm run dev` | 開発サーバが起動します（ http://localhost:5281 ） |
| 3 | ブラウザで開く | `?m=39201`（市区町村コード）や `?h=5.0`（津波高）を付けると、その状態で開きます |

- 初回は地形・建物のデータを外部配信元から読み込むため、**数秒〜十数秒ほど画面が暗いまま**になります。そのままお待ちください。
- 通信が必要です（オフラインでは表示できません）。

## 3. 画面の見方

パソコンでは左側に操作パネル、右上に浸水深の表示が出ます。スマホでは操作パネルが画面下の「ボトムシート」になります。

```
┌──────────────────────────────────────────────────────────┐
│ [赤／黄バナー]（問題があるときだけ上部に表示・タップで閉じる）│
├────────────────────┬────────────┬────────────────────────┤
│ 操作パネル          │▼ パネルを閉じる│  地図をタップ → その地点の浸水深を表示 │
│  南海トラフ 津波浸水3D│                                        │
│  地域を選ぶ         │                                         │
│  内閣府 津波高      │            3D 地図（ここをドラッグ／タップ）  │
│  津波の高さ（T.P.基準）│                                       │
│  重ねる情報         │                                         │
│  視点リセット／状態 │                                         │
│  免責・出典         │                                         │
└────────────────────┴─────────────────────────────────────┘
```

| 場所 | 名前（画面の表記） | 役割 |
|---|---|---|
| パネル上部 | 地域を選ぶ | 「都道府県」→「市区町村」の順に選びます。「検索」に名前の一部を入れると絞り込めます。「この市町村へ移動」で地図がその市区町村へ飛びます |
| パネル | 内閣府 津波高（海岸での最大値） | 選んだ市区町村の `2025 最大`／`2025 平均`／`2012 最大`／`浸水面積（2025）`。値が無い項目は「データなし」 |
| パネル | 津波の高さ（T.P.基準） | プリセット 4 ボタン（`2025 最大` `2025 平均` `2012 最大` `手動`）とスライダー（0〜35 m・0.1 m 刻み）。右上に現在値 |
| パネル | 重ねる情報 | `公式浸水想定を重ねる（重ねるハザードマップ）`（凡例付き）、`建物を表示`、`LOD2`、`淡色地図`／`航空写真`、`水面を表示` |
| パネル | 視点リセット | カメラを選択中の市区町村（未選択時は初期位置）の上空へ戻します。右側に建物の読込状態 |
| パネル下部 | 免責・出典 | 常に表示されます |
| パネル横 | ▼ パネルを閉じる ／ ▲ パネルを開く | パネルの表示・非表示 |
| 右上 | 浸水深リードアウト | タップした地点の浸水深と地盤高 |
| 画面上端 | バナー | データ読込の失敗などをお知らせ |

## 4. 基本操作 3ステップ

1. **市区町村を選ぶ**: 「都道府県」を選んでから「市区町村」を選びます（「検索」に「高知」「黒潮」などと入れて絞り込むこともできます。1 件に絞れたら Enter でそのまま選べます）。選ぶと津波高の表が出て、水面が `2025 最大` の高さになります。「この市町村へ移動」で地図がその場所へ飛びます。
2. **津波の高さを決める**: `2025 最大`／`2025 平均`／`2012 最大` のボタンで内閣府の値を切り替えるか、スライダーで自由に設定します（スライダーを動かすと `手動` になります）。
3. **地点をタップして浸水深を確認**: 地図上の調べたい場所を1回タップ（クリック）すると、右上に `浸水 X.XX m` または `浸水なし` と表示されます。表示の箱をタップすると消えます。

## 5. 操作一覧

### マウス（パソコン）

| したいこと | 操作 |
|---|---|
| 地図を動かす（移動） | 左ボタンでドラッグ |
| 拡大・縮小 | マウスホイール、または右ボタンでドラッグ |
| 傾ける・回す | 中ボタン（ホイール）でドラッグ、または Ctrl を押しながら左／右ボタンでドラッグ |
| 浸水深を調べる | 動かさずに1回クリック |

### タッチ（スマホ・タブレット）

| したいこと | 操作 |
|---|---|
| 地図を動かす（移動） | 1本指でドラッグ |
| 拡大・縮小 | 2本指でピンチ（広げる／つまむ） |
| 傾ける | 2本指を同じ方向にドラッグ |
| 回す | 2本指を反対方向にドラッグ |
| 浸水深を調べる | 動かさずに1回タップ |

### パネルの操作

| 部品 | 操作 |
|---|---|
| 都道府県／市区町村 | プルダウンから選択。「すべての都道府県」のままでも、市区町村は都道府県ごとにまとまって並びます |
| 検索 | 市区町村名の一部（ひらがな不可・漢字）や都道府県名、コード先頭で絞り込み。`6 / 6 件` のように件数が出ます |
| この市町村へ移動 | 選択中の市区町村の上空へカメラを移動 |
| プリセット | ボタンを押すと、その値がスライダーに入ります。選択中のボタンは青く強調され、値が無いボタンは押せません |
| スライダー | 左右にドラッグ。0.1 m 刻み。動かすと `手動` に切り替わります |
| 視点リセット | 押すと初期視点に戻ります |
| ▼ パネルを閉じる | 地図を広く見たいときに。もう一度押す（▲ パネルを開く）と戻ります |

## 6. 津波の高さの決め方

- **内閣府の津波高は「海岸線での最大値」です。** 市域全体へ同じ高さの水面を置くため、海岸から離れた内陸では**過大**に、河川沿いなど局所的には**過小**になることがあります。
- **震度から津波の高さは直接換算できません。** 震度は「揺れの強さ」、津波の高さは「海底地形や断層の動き方」で決まる別の指標です。
- まずは `2025 最大` → `2025 平均` → `2012 最大` と切り替えて、「どの高さから自宅や職場が浸かるか」を見比べるのがおすすめです。

| プリセット表記 | 意味・出典 |
|---|---|
| 2025 最大 | 内閣府 2025 年公表「市町村別一覧表」の最大津波高（複数ケースの最大） |
| 2025 平均 | 同一覧表の平均津波高（各ケースの平均） |
| 2012 最大 | 内閣府 2012 年公表の市町村別最大津波高 |
| 手動 | スライダーで自由に設定した値 |

- **T.P.（東京湾平均海面）** とは、日本の標高の基準となる海面の高さです。「T.P. 16 m」は「東京湾の平均的な海面から 16 m 上」の意味で、地面からの高さではありません。
- 表の「浸水面積（2025）」は内閣府一覧表の浸水面積（ha）で、水面の高さには影響しません。

## 7. 見え方の読み取り方

| 見えるもの | 意味 |
|---|---|
| 半透明の青い水面 | 設定した津波の高さ。**水面の下にある地面は浸水想定**です |
| 建物が青く着色されている | その部分が水面より低い（水面下 2 m で最も濃い青）。建物のどの階まで浸かるかの目安です |
| 地形や建物が水面を突き抜けている | 水面より高いので、**その高さの津波では浸水しません** |
| 黄〜赤〜紫の塗り分け（公式浸水想定 ON 時） | 国のハザードマップの津波浸水想定。色が濃いほど深い。凡例はパネルに表示 |

### 公式浸水想定の凡例（浸水深）

| 色 | 浸水深 |
|---|---|
| うすい黄 | 0.3 m 未満 |
| 黄 | 0.3〜0.5 m |
| クリーム | 0.5〜1 m |
| うすい橙 | 1〜3 m |
| ピンク | 3〜5 m |
| 赤 | 5〜10 m |
| 赤紫 | 10〜20 m |
| 紫 | 20 m 以上 |

出典: ハザードマップポータルサイト。想定区域が公表されていない場所は何も塗られません。

### 浸水深リードアウト（右上）の読み方

| 表示例 | 意味 |
|---|---|
| `浸水 1.23 m` ／ `地盤 T.P. +2.37 m／水位 T.P. 3.6 m` | タップ地点の地面は T.P. 2.37 m、水位は 3.6 m なので、差の 1.23 m が浸水深です |
| `浸水なし` ／ `地盤 T.P. +4.12 m（水面より 0.52 m 高い）` | 地面が水面より高いため、この高さの津波では浸かりません |
| `地形データなし` `計測できません` | 地形を読み込めていない、または地形以外をタップしています。少し待って地面をタップし直してください |

- 遠くから見た状態でタップすると地盤高に誤差が出ることがあります。調べたい場所に近づいてからタップすると正確です。

## 8. 表示設定

| 項目（画面の表記） | 既定 | 説明 |
|---|---|---|
| 公式浸水想定を重ねる（重ねるハザードマップ） | OFF | 国土地理院ハザードマップポータルサイトの津波浸水想定を重ねます。ON にすると凡例が出ます |
| 建物を表示 | ON | OFF にすると建物を消して地形と水面だけを見られます |
| LOD2（対応都市のみ・重い） | OFF | 屋根形状まで再現した詳しい建物。対応する都市だけ切り替わり、通信量・メモリが増えます |
| 淡色地図（既定）／航空写真 | 淡色地図 | 国土地理院の地図。航空写真は実際の街並みと重ねて見たいときに |
| 水面を表示 | ON | OFF にすると水面を消せます（建物の青い着色はそのまま残ります） |

- パネル下の `建物: …` の表示で、建物データの読込状態を確認できます。

## 9. よくある質問・困ったとき

| 症状 | 原因と対処 |
|---|---|
| 画面が暗いまま／地図が出ない | 初回は地形・建物の読込に数秒〜十数秒かかります。しばらく待っても変わらない場合は通信状態を確認して再読み込みしてください |
| 市区町村が「データなし」と出る | 一覧表に載っていない市区町村、または該当項目の値が公表されていません。スライダー（手動）で高さを指定してください |
| プリセットのボタンが押せない | その項目の値が無い（データなし）ためです。他のボタンか手動をお使いください |
| 建物が出ない | 「建物を表示」が ON か確認してください。PLATEAU の整備がない都市では建物は表示されません |
| 公式浸水想定が出ない | 想定区域が公表されていない場所か、遠すぎる（ズームが粗い）可能性があります。沿岸へ寄ってご確認ください |
| **黄色いバナー**（建物モデルの読込失敗） | 一部の建物データを取得できませんでした。通信状態を確認し、再読み込みしてください。バナーはタップで閉じられます |
| **赤いバナー**（地形データの読込失敗） | 地形が取得できず、平らな地面で表示中です。浸水深の計測もできません。通信復旧後に再読み込みしてください |
| 動きが重い・カクつく | 「LOD2」を OFF に。「建物を表示」を一時的に OFF にするのも有効です |
| 「お使いの環境では 3D 表示（WebGL）が利用できません」 | ブラウザのハードウェアアクセラレーションを有効にするか、最新の Safari／Chrome／Edge／Firefox でお試しください |
| 視点を見失った | 「視点リセット」を押してください |

## 10. スマホでの使い方の注意

- 操作パネルは画面下のボトムシートです。上下にスクロールでき、「▼ パネルを閉じる」で地図を全画面にできます。
- **横向き（ランドスケープ）推奨**: 地図が広く見え、ボトムシートと両立しやすくなります。
- **発熱・電池**: 3D 描画は負荷が高く、端末が温かくなります。長時間の連続利用は避け、「LOD2」は OFF のままがおすすめです。
- **通信量の目安**: 初回に本体約 6 MB ＋ 地形・建物データで**数十 MB 規模**。**Wi-Fi 環境でのご利用を推奨**します。
- 画面のピンチ拡大はブラウザではなく地図の拡大に使われます。文字を大きくしたい場合はブラウザの文字サイズ設定をご利用ください。
- 現在の市区町村と高さは URL（`?m=…&h=…`）に反映されるので、そのまま共有できます。

## 11. 用語集

| 用語 | 意味 |
|---|---|
| T.P.（東京湾平均海面） | 日本の標高の基準となる海面。「T.P. 3 m」は東京湾の平均海面から 3 m 上の高さ。地面からの高さではありません |
| 津波高（海岸最大値） | 内閣府一覧表の値。満潮位と地殻変動を考慮した、海岸線での津波の最大の高さ（T.P. 基準） |
| 浸水深 | 水面の高さと地面の高さの差。「浸水 1.2 m」なら、その地点で地面から 1.2 m まで水に浸かる想定です |
| 重ねるハザードマップ | 国土地理院「ハザードマップポータルサイト」の機能。都道府県が公表した津波浸水想定などを地図に重ねられます |
| ジオイド／ジオイド高 | 平均海面を陸地まで延長した仮想の面がジオイド。地形データ（楕円体高）と T.P. を合わせるために使います。本アプリは国土地理院 GSIGEO2011（japan-geoid）で自動補正します |
| LOD | Level of Detail（詳しさの段階）。LOD1 は箱型の簡易建物、LOD2 は屋根形状まで再現した建物 |
| 3D Tiles | 大量の3Dデータを、見ている範囲だけ少しずつ読み込むための配信形式。建物データに使っています |
| PLATEAU（プラトー） | 国土交通省が進める、日本全国の3D都市モデルを整備・公開するプロジェクト |
| 地理院タイル | 国土地理院が配信する地図画像。「淡色地図」「航空写真」に使っています |
